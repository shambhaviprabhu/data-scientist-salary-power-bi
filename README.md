📊 Data Professional Survey Dashboard (Power BI)
📌 Project Overview

This Power BI project analyzes responses from a global Data Professionals Survey to uncover insights about demographics, salaries, skills, career difficulty, and job satisfaction within the data industry.

🎯 Objectives

Understand the geographic distribution of data professionals

Compare average salaries across different data roles

Identify popular programming languages

Analyze perceived difficulty of entering the data field

Measure happiness levels related to salary and work-life balance

🛠 Tools & Technologies

Power BI Desktop

Power Query for data cleaning and transformation

DAX for calculated measures and KPIs

🔄 Data Preparation

Removed duplicate records

Standardized country names, job titles, and categorical values

Created calculated measures for averages, counts, and ratings

📈 Dashboard Highlights

Tree Map: Country-wise distribution of survey takers

Bar Chart: Average salary by job title

Stacked Column Chart: Favorite programming languages

Donut Chart: Difficulty level to break into data roles

KPI Cards & Gauges:

Average age of respondents

Happiness with salary

Happiness with work-life balance

🔍 Key Insights

Data Scientists report the highest average salaries

Python is the most preferred programming language

Most respondents rate breaking into data roles as moderately difficult

Work-life balance satisfaction is higher than salary satisfaction overall

📁 Use Case

This dashboard is useful for:

Aspiring data professionals exploring career paths

Recruiters and hiring managers understanding market trends

Anyone interested in data industry insights
